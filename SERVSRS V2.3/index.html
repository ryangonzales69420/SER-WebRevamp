    About

    What is SER?

    Scripted Events Reloaded (SER) is a scripting plugin for SCP: Secret Laboratory. It lets server owners create custom events, commands, and gameplay features using text-based scripts instead of writing and compiling a C# plugin.

    SER Blocks is a visual editor that helps you build scripts using blocks. Export your finished script and place it in your server's SER script directory.

    View the official SER project

    Getting started

    Install SER

    Download the plugin build that matches your server framework. The official releases page contains the available files and version information.

    Download for LabAPI ↗ Download for EXILED ↗
    1. Open the latest official release and select the plugin build that matches your framework.
    2. Install the plugin using the instructions for your framework and hosting environment. The LabAPI build is named SER.dll; the EXILED build is named SER-Exiled.dll in the project's release packaging.
    3. Start your server and check the console for plugin loading messages or errors.
    4. Use serhelp start or serstatus to help locate and inspect the SER script directory.

    Important: The plugin DLL and your script files are different things. Install the plugin first, then add individual .ser scripts to the script directory.

    Scripts

    Adding a SER script

    1. Create or export a script with the .ser extension.
    2. Find the script directory using serhelp start or serstatus in your server console.
    3. Place your script in that directory. A .txt extension is also supported by SER if your host restricts .ser files.
    4. Run serrun yourScriptName to execute a particular script. Omit the file extension in the command.
    5. Run serreload when you want to refresh the complete script directory.
    6. Run serstatus to inspect loaded scripts, failures, and conflicts.

    Tip: SER also reloads file-backed scripts before execution and refreshes the script directory at round restarts.

    My script isn't loading
    1. Confirm that the SER plugin loaded successfully.
    2. Check that your file is in the script directory reported by SER.
    3. Run serstatus and look for failed, disabled, or conflicting paths.
    4. Check the server console for script validation errors.
    5. Make sure the script has a valid SER section and syntax.
    6. Try serreload to refresh the directory.

    If the problem persists, consult the official documentation or report the error with the relevant console output.

    Report a problem on GitHub ↗
    serstatus or another command isn't working

    Make sure you are entering the command in the server console or another supported command interface, not in the visual editor or an ordinary player chat box.

    • If serstatus is unknown, verify that SER actually loaded during server startup.
    • If serreload is denied, check the command's permissions and the console output.
    • If serrun cannot find your script, verify its name and the directory reported by SER.

    Tips

    Good to know

    • SER scripts use sections introduced by flags such as !-- OnEvent RoundStarted.
    • Use serhelp on the server to discover available commands and language features.
    • Use serexamples to generate example scripts supported by your installed SER version.
    • Files and folders whose names begin with # are skipped during script discovery.
    • Use serstatus to diagnose failed, disabled, excluded, or conflicting scripts.
    • Check the current documentation before copying older SER tutorials, because the syntax has changed between versions.
