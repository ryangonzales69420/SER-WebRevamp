    About

    What is SER?

    Scripted Events Revamped is a scripting layer for SCP: Secret Laboratory dedicated servers. It lets you write plain-text scripts that react to in-game events like round starts, player deaths, and custom commands, without touching server code.

    This visual editor turns those scripts into draggable blocks. Every workspace you build here exports as plain SER text you can drop into your script folder.

    Installation

    Get it running

    1. Download the .ser file from the Code tab.
    2. Put it in the SER script directory & run serhelp start in the server console to see where that is.
    3. If your host blocks .ser, rename it to .txt.
    4. For a new manual script, run serrun name in the console.
    5. After editing, run serreload to pick up the changes.
    6. Nothing happening? Run serstatus to list what's loaded.

    Tips

    Good to know

    • Every script needs at least one When block.
    • Inside a command, @sender is whoever typed it.
    • A Forever loop must contain a Wait, or the server will hang.
    • Use Save player data to remember values across rounds.
    • @evPlayer only exists inside events that provide a player.
    • Variables live only inside a single script run. Use player data to persist.
