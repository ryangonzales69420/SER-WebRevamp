# About SER
Scripted Events Reloaded (SER) is an **SCP:SL** plugin that adds a custom scripting language for server-side events.

## Main goal
Making plugins with C# is NOT an easy thing, especially for beginners. If you want to get started with SCP:SL server-side scripting, SER is a great way to begin.

SER simplifies the most essential plugin features into a friendly package. All you need to get started is a text editor and a server!

# This Fork (web revamp)
SER contains a node-based editor similar to scratch. This is a copied version of that but expanded to have much better logic, more blocks, templates, and more. This is to expand and make SER even more open to beginners than already, with zero code being needed to make even advanced mods like your own custom roles or gambling coin.

Any feedback is greatley apprechiated through the feedback button. I do expect of issues with actually testing it in live SCP:SL servers, I recommend testing it on servers that do not have high playercounts until you know your logic or my code doesn't have any issues.

## Content
Below you can find present and future (planned) content and the future of this project
### Current
- Start
  - The trigger to the script, with options like a custom server command, when the round starts, when a player uses or eqiups an item, etc.
- Players
  - Modify health, effects, location, size, etc of players.
- Messages
  - Notify the server with CASSIE announcements, hints and messages.
- World
  - Decontamination, warhead, friendly fire, doors, lights, and elevator.
- Logic & Values
  - For loops, if, tables & lists.
- Variables & saving
  - Basic variables are included and some more expiremental ones in the advanced menu.
- Server
  - Prints, run commands, run other scripts.
- Libraries
  - Libraries are minor extra content that is often able to be made with existing blocks, but it's just there to save time. Most of these are expiremental implementations with logic that cannot be made otherwise and is made to work with other server plugins. Webhooks, primitive objects, UCR & more.
