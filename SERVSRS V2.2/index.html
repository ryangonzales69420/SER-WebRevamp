    About

    What is SER?

    Scripted Events Revamped is a scripting layer for SCP: Secret Laboratory dedicated servers. It lets you write plain-text scripts that react to in-game events like round starts, player deaths, and custom commands, without touching server code.

    This visual editor turns those scripts into draggable blocks. Every workspace exports as plain SER text you can drop into your script folder.

    Installation

    Get it running

    1. Download the .ser file from the Code tab.
    2. Put it in the SER script directory and run serhelp start in the server console to see where that is.
    3. If your host blocks .ser, rename it to .txt.
    4. For a new manual script, run serrun name in the console.
    5. After editing, run serreload to pick up the changes.
    6. Nothing happening? Run serstatus to list what's loaded.

    Shortcuts

    Work faster

    • Ctrl + K finds any block by name or purpose.
    • Ctrl + Z and Ctrl + Shift + Z undo and redo.
    • Ctrl + S saves an editable blocks project.
    • Click any line in Checks to jump to the block that caused it.

    Tips

    Good to know

    • Every script needs at least one When block.
    • Inside a command, @sender is whoever typed it.
    • A Forever or While loop must contain a Wait, or the server can hang.
    • Use Save player data or Add to saved data to remember values across rounds.
    • @evPlayer only exists inside events that provide a player.
    • Variables live only inside a single script run. Use player data to persist.
    • Blocks in the Libraries category do several steps at once. Open them to see exactly what they generate.
